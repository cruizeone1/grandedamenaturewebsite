# Grande Dame Nature

Static homepage for Grande Dame Nature — botanical body care rooted in ancestral wisdom.

## Structure

- `index.html` — page markup
- `styles.css` — layout and styling
- `script.js` — mobile navigation
- `assets/` — logo, icons, and section images

## Local preview

Open `index.html` in a browser, or serve the folder locally:

```bash
npx serve .
```

## Deploy

This site is deployed to Cloudflare Pages from the `main` branch. No build step is required.
